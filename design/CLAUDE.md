# Design Directory (solo)

Keep design docs short. Use what helps; skip what doesn't.

## GDD Files (`design/gdd/`)

A short Markdown file per game/system. Suggested structure:

1. **What it is** — one sentence
2. **Core mechanic** — how the player plays it
3. **Tuning knobs** — every magic number that might need adjustment
4. **What "done" looks like** — 1-3 testable checks

That's it. Don't pad a Flappy Bird doc into 8 sections.

**File naming:** `[name].md` (e.g. `flappy-bird.md`)
